Sales & POS All users

Making a Sale

Add items to the cart then finalise to generate a receipt.

  • Select a product from the dropdown or type / scan the SKU/barcode
  • Enter the quantity (defaults to 1)
  • Click Add to Cart
  • Repeat for more items
  • Choose a Payment Method, enter a reference if required
  • Click Finalise Sale
Go to Sales

Cart Management

Review and adjust items before finalising.

  • The cart shows each item, qty, unit price and line total
  • Use Remove next to an item to delete it from the cart
  • Use Clear Cart to start over
  • Output VAT is calculated automatically per item based on its VAT category

Payment Methods Supported

  • Cash
  • Credit Card (MCB, SBM, MauBank, AfrAsia)
  • JuiceApp
  • Blink
  • MyT Money
  • Other (with optional reference)

Receipts

A full receipt is generated after every sale.

  • Shows all items, VAT breakdown, payment method
  • Can be printed directly from the browser
  • Accessible later from the Sales history list
Tip: Scan a barcode with a USB scanner — it populates the SKU field automatically without any extra software.

Products All users (edit: Admin)

Adding a Product

  • SKU — unique barcode or internal code
  • Name — product description
  • Brand / Lodgement — optional fields
  • VAT Category — Standard (15%), Zero-rated (0%), Exempt
  • Cost Price — purchase cost per unit
  • Selling Price — retail price (inclusive of VAT)
  • Low Stock Level — warning threshold
Go to Products

Editing & Deleting

Admins can edit any product at any time. Deletion is only permitted for products with no sales or purchase history to preserve data integrity.

  • Products with history show "Cannot delete (has history)"
  • Edit is always available for admins

VAT Categories

  • Standard — 15% Mauritius VAT applied on sales
  • Zero-rated — taxable but at 0% (e.g., exports). Input VAT still recoverable
  • Exempt — no VAT charged; input VAT not recoverable

Purchases All users

Recording a Purchase

Use this page to receive stock into the system.

  • Select the product and enter quantity received
  • Enter Unit Cost (defaults to product cost price)
  • Fill in supplier details, invoice number and expiry date
  • Input VAT is auto-calculated for Standard and Zero-rated products
Go to Purchases

Fields Explained

  • Amount Ex-VAT — purchase cost before VAT
  • VAT Amount — input VAT (15% for Standard/Zero)
  • Total incl. VAT — full invoice value
  • Input VAT — recorded for your VAT return

Stock All users

How Stock Is Calculated

Stock level = total purchases received minus total units sold, for each product.

  • Rows highlighted in amber are at or below the low-stock threshold
  • Rows highlighted in red are negative (oversold)
  • Stock value shown at cost price
Go to Stock

Low Stock Alerts

Each product has a configurable Low Stock Level set in the Products page. When stock falls to or below that level the dashboard and stock page will flag it.

Float Management All users

Opening a Float

Start each shift by recording the cash float in the till.

  • Enter the opening cash amount
  • Click Open Float
  • Only one float session can be open at a time per cashier
Go to Float

Closing a Float

At end of shift, count the cash and record the closing amount.

  • Enter the closing cash amount
  • Click Close Float
  • The difference between opening and closing is shown in history

VAT Summary All users

VAT Calculation

Mauritius VAT apportionment is applied automatically:

  • Output VAT — collected on Standard-rated sales
  • Input VAT (raw) — paid on all purchases
  • Apportionment ratio — taxable sales ÷ total sales
  • Adjusted Input VAT — raw input VAT × apportionment ratio
  • VAT Payable — Output VAT − Adjusted Input VAT
Go to VAT

Barcodes All users

Generating Barcodes

A Code 128 barcode image is generated for every product based on its SKU.

  • Go to Barcodes to see all products
  • Click Download to save a PNG barcode image for printing
Go to Barcodes

Barcode Decoder

Upload an image of a barcode to look up the product.

  • Requires pyzbar library to be installed
  • Supports JPG, PNG, and most common image formats
  • Returns matching product name, category, and price
Go to Decoder

Physical Stock Take Admin only

Conducting a Count

Enter the actual physical quantities counted in the warehouse/shop floor.

  • Select the count date (defaults to today)
  • For each product, enter the physically counted quantity
  • Variance (Physical − Ledger) is calculated in real-time
  • Green = overage, Red = shortage
  • Add notes for any damaged or expired items
  • Click Save Stock Count
Go to Stock Take

Stock Variance Report

Compare physical counts against the system ledger for a specific date.

  • Select a count date to see the variance analysis
  • Shows Overage / Shortage / Exact for each product
  • Total variance in quantity and value
  • Summary boxes for overages vs shortages
Go to Variance
Tip: Run a stock take at the end of each month and compare to the Stock Report to identify shrinkage or data-entry errors.

Database Maintenance Admin only

Database Backup

Creates a timestamped ZIP archive of the SQLite database.

  • Click Download Backup to download the ZIP
  • Backups are also stored in the backups/ folder on the server
  • An automated backup email is sent daily at 2:00 AM (if email is configured)
Go to Maintenance

Purge Old Records

Delete audit log entries older than a specified number of days to reduce database size.

  • Default: records older than 365 days
  • Sales, purchases and stock data are never purged — only audit logs
  • A warning banner appears when the database exceeds 50 MB

Size Warning

A yellow warning banner appears on every page when the database file exceeds 50 MB. Click the banner to go directly to the maintenance page.

User Management Admin only

Creating Users

  • Username must be unique
  • Password must be at least 6 characters
  • Tick Admin to grant admin access
  • Non-admin users are cashiers with limited access
Go to Users

Admin vs Cashier

  • Cashier — Sales, Purchases, Stock, VAT, Float, Takings, Reports, Barcodes
  • Admin — All cashier access + Product edit/delete, Users, Physical Stock, Database, Email Settings, Audit Logs

Resetting Passwords & Status

  • Admins can reset any user's password
  • Admins can enable/disable user accounts
  • At least one active admin must exist at all times
  • You cannot disable your own account

Audit Logs Admin only

What Is Logged

All significant actions are logged automatically, including:

  • User logins and logouts
  • Password changes and resets
  • User account creation, enable/disable
  • Physical stock counts
  • Database backups and purges
  • Email settings changes
  • Report saves
Go to Audit Logs

Email Settings Admin only

Configuration

Enter your SMTP email server details to enable email features.

  • SMTP Server — e.g. smtp.gmail.com
  • SMTP Port — typically 587 (TLS) or 465 (SSL)
  • Sender Email — the address emails are sent from
  • Password — use an App Password for Gmail (not your main password)
Go to Email Settings

Automated Daily Backups

Enter comma-separated recipient addresses in the Backup Recipients field. The system will email the database backup every day at 2:00 AM.

Gmail Setup

  1. Enable 2-Step Verification on your Google account
  2. Go to Google Account → Security → App Passwords
  3. Generate an app password for "Mail"
  4. Use smtp.gmail.com, port 587
  5. Paste the 16-character app password in the Password field
